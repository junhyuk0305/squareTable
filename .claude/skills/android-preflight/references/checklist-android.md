# 안드로이드 체크리스트 — 스캐너가 못 잡는 것

스캐너(`scan-android.mjs`)는 **코드에 적혀 있는 것**만 본다. 아래는 **코드에 안 적혀 있어서** 못 보는 것들이다.
**이번에 바뀐 코드에 해당하는 항목만** 고른다. 전 항목 순회는 첫 감사 1회면 충분하다.

---

## §1. 사용자가 바꾼 폰 설정 (안드로이드 제보의 상당수가 여기서 온다)

| 설정 | 어디서 | 무엇이 깨지나 |
|---|---|---|
| **글꼴 크기** (최대 2.0배) | 설정 → 디스플레이 → 글꼴 크기 | 고정 height 상자의 글자가 잘린다. 버튼 두 줄이 되면서 화면 밖으로 밀린다 |
| **화면 크기(displayScale)** | 설정 → 디스플레이 → 화면 크기 | 글꼴과 **곱해진다**. 둘 다 최대면 체감 2.5배 이상 |
| **제스처 내비게이션 ↔ 3버튼** | 설정 → 디스플레이 → 탐색 모드 | 하단 inset 높이가 달라진다(제스처바 vs 버튼바). 탭바가 가려지거나 붕 뜬다 |
| **다크 모드** | 설정 → 디스플레이 | `userInterfaceStyle: automatic` 이라 따라간다. 대비가 무너지는 곳 확인 |
| **배터리 최적화** | 설정 → 배터리 → 앱별 | 백그라운드 푸시 지연·미도달. 삼성은 기본이 더 공격적이다 |
| **애니메이션 끄기**(개발자 옵션·접근성) | 설정 → 접근성 | `Appear` 등 등장 애니가 안 돌아 "화면이 비어 보인다"가 될 수 있다 |

> 제보를 받으면 **기기 모델·안드로이드 버전·위 설정 변경 여부**를 먼저 묻는다.
> 코드를 열기 전에 이걸 물으면 한 회차를 통째로 아낀다.

## §2. 제조사 스킨 (One UI 등)

- **삼성 One UI**: 알림 채널 UI·배터리 절약 정책·키보드(삼성 키보드)가 AOSP 와 다르다. 국내 사용자 다수가 삼성이다.
- **기본 키보드가 다르다**: 삼성 키보드·구글 키보드의 높이·툴바 유무가 달라 `KeyboardShift` 가 재는 값이 달라진다.
- **한글 입력 조합 중 상태**: 조합 중인 글자가 `onChangeText` 로 들어오는 타이밍이 키보드마다 다르다 —
  입력 중 즉시 검증·즉시 검색을 거는 곳은 실기기에서 한 번 쳐 본다.

## §3. 생명주기·백그라운드

- **Doze/앱 대기 버킷**: 화면이 꺼진 채 오래 두면 `setInterval` 이 멈춘다. 복귀 시 데이터 재조회가 되는지.
- **프로세스 종료 후 복귀**: 안드로이드는 메모리가 모자라면 앱을 죽인다. 다시 열면 `expo-router` 가
  마지막 경로로 복원하는데, 그 화면이 **세션 없이 열리는지** 확인(로그인 화면으로 튕기는가, 빈 화면인가).
- **알림 탭 → 앱이 죽어 있던 경우**: 콜드 스타트 경로에서 `bindNotificationTapRouting` 이 이미 걸려 있는가.

## §4. 권한 런타임 흐름 (코드엔 문자열만 보이고 동작은 기기에서만)

- **마이크**: 거부 → "다시 묻지 않음"까지 간 상태에서 다시 누르면 무슨 일이 나는가(설정으로 보내는 안내가 있는가).
- **알림(POST_NOTIFICATIONS, Android 13+)**: 앱 첫 실행에 묻지 않고 "알림 켜기"에서만 묻는 규칙이 지켜지는가
  (출시서류_안드로이드 12번 문서 §2 의 우리 답안).
- **사진**: Android 13+ 는 시스템 사진 선택기라 권한 팝업이 아예 안 뜬다. 12 이하 기기에서는 뜬다 — 둘 다 본다.

## §5. 레이아웃 (edge-to-edge 전제)

- 하단 inset 은 **탭바가 소유**한다(`native-audit` 규칙). 탭바 없는 화면은 누가 갖는지 확인.
- 상태바 뒤로 콘텐츠가 깔린다 — 스크롤 최상단에서 첫 요소가 시계와 겹치지 않는가.
- **가로**: API 36 은 600dp+ 에서 세로 고정을 무시한다. 폴더블을 펴거나 태블릿에서 열어 본다.
- **멀티윈도우/분할 화면**: 창이 작아진 상태에서 최소 레이아웃이 버티는가.

## §6. 실기기에서만 확인 가능 (사용자에게 넘길 목록의 원천)

각 항목은 ①어디로 가서 ②무엇을 하고 ③무엇이 보이면 정상인지로 쓴다. 설정을 바꿔야 하면 **설정 경로까지** 적는다.

- 글꼴 '가장 크게' → 홈·목록·버튼에서 글자 잘림/겹침
- 뒤로가기 제스처(화면 왼쪽 끝에서 밀기) → 모달이 모달만 닫히는가, 앱이 통째로 나가지 않는가
- 알림 실제 도착(잠금화면·헤드업·소리) — 이건 FCM 키까지 맞아야 나온다
- 마이크 권한 거부 후 재시도 흐름
- 화면 꺼 두고 10분 뒤 복귀 → 데이터가 갱신되는가
- 앱을 강제 종료 후 알림 탭 → 해당 화면으로 가는가

## §7. 이 체크리스트에 항목을 추가하는 기준

실기기 제보로 **실제로 물린 것**만 추가한다. "그럴 수도 있다"는 항목은 넣지 않는다 —
길어지면 아무도 안 보고, 안 보는 체크리스트는 없는 것과 같다.
추가할 때는 **어느 회차에서 어떻게 드러났는지** 한 줄을 같이 남긴다.
