# 사례 — iOS 2차 실측 2건 + 같은 부류 전수 점검 (2026-09-07)

개발용 앱(dev client)이 폰에 붙은 뒤 나온 2건. 1차(09-06)와 달리 **둘 다 "안 되는 것"이 아니라
"다르게 되는 것"** 이라, 스크린샷 없이는 영원히 못 잡았을 부류다.

## 1. 할일의 데이파트 그룹이 몇 px 만 보이고 잘렸다

**제보**: "할일에서 할일들이 토글인데 잘려서 안 보임."

**층**: 측정 기반 레이아웃(공용 `Collapse`).

**메커니즘**: `Collapse` 는 `onLayout` 으로 내용 높이 `h` 를 재서 `height: 0 → h` 로 연 뒤,
**그 높이를 계속 씌운 채로 두었다.** 측정이 내용이 차기 전(패딩만 있는 상태)에 한 번 들어오면
그 작은 값이 그대로 굳는다. 스크린샷에서 내용이 불투명하게 보인 것이 근거다 —
`opacity` 와 `height` 가 같은 값 `v` 를 쓰므로, 흐리지 않다 = `v≈1` = **애니메이션은 끝났고 `h` 가 작다.**

**수정**: 여는 애니메이션이 끝나면(마운트 기준 단일 타이머, 재측정 횟수와 무관) **높이 구속을 놓는다.**
왜 측정이 낡았는지와 무관하게 이 부류가 통째로 사라진다. 사진 로드·줄바꿈·행 추가로 내용이
나중에 커지는 경우까지 같이 막힌다.

**교훈**: **잰 값을 영구히 씌우지 않는다.** 애니메이션에 필요한 동안만 씌우고, 끝나면 놓는다.
측정은 언제든 낡을 수 있고, 낡은 측정으로 잘린 화면은 사용자에게 "고장"으로 보인다.

## 2. 헤더 제목이 iOS에서만 가운데로 밀렸다 (★이 스킬 §핵심 7의 출처)

**제보**: "설정 글씨가 오른쪽으로 밀려서 왼쪽에 과도한 여백이 생겼잖아. 왼쪽 정렬이 되어야지."

**메커니즘**: 코드에는 왼쪽 정렬 의도가 **주석까지 달려** 있었다
(`categories.tsx`: "네이티브 타이틀 앵커(~17px)를 콘텐츠 거터(20)로 맞춰 paddingLeft 3 = 20-17").
그런데 `headerTitleAlign` 은 native-stack 공식 문서에 이렇게 적혀 있다 —

> **"Not supported on iOS. It's always `center` on iOS and cannot be changed."**

타입 오류도 콘솔 경고도 없다. 안드로이드에서는 의도대로 왼쪽에 붙으니 **다 된 줄 알았다.**

**수정**: 슬롯을 바꾼다. iOS 네이티브 내비바는 **타이틀 슬롯을 항상 가운데** 두므로,
왼쪽에 붙이려면 `headerTitle: () => null` + `headerLeft: () => <제목/>`.
양 플랫폼이 같은 슬롯을 쓰므로 플랫폼 분기가 필요 없다.
뒤로가기가 있는 화면(업무 패널)은 **화살표와 제목을 한 줄로 묶어** 왼쪽 슬롯에 넣는다.

**교훈**: 플랫폼 옵션은 **"쓸 수 있다"와 "먹는다"가 다르다.** 타입이 통과한다고 동작하는 게 아니다.
의심되면 공식 문서의 "Only supported on …" 표기를 먼저 확인한다.

## 3. 같은 부류 전수 점검 (제보 없이 내가 찾은 것)

사용자 지시로 코드베이스 전체를 훑었다. 결과:

| 검사 | 결과 |
|---|---|
| iOS에서 무시되는 내비 옵션 (`headerTitleAlign` 등 6종) | 실사용 **0건**(위 수정으로 전부 제거됨) |
| RN 기본 `SafeAreaView`(iOS 전용) 오용 | 0건 |
| `textAlignVertical` 13건 | **무해** — 전부 멀티라인 `'top'`(iOS 기본값과 같음). `'center'` 1건은 이미 iOS용 대칭 패딩으로 보정돼 있고 주석도 있다 |
| `importantForAccessibility` 2건 | **1건 결함** — `Sparkline.tsx` 가 iOS 짝(`accessibilityElementsHidden`) 없이 안드로이드 prop 만 썼다 → 라벨 없는 장식 그래프의 막대가 VoiceOver 에 그대로 읽힌다. 수정함 |
| `android_ripple` · `includeFontPadding` · `overScrollMode` 등 | 0건 |

**이 점검이 스킬에 남긴 것**: 규칙 `ios-ignored-nav-option`(🟡) · `ios-a11y-pair`(🟡).
둘 다 픽스처로 RED 확인했다.
