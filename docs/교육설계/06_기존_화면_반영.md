# 06. 기존 화면 반영

분기 B. 실행 순서 3번. 새 화면을 늘리지 않고 지금 있는 자리에 교육 모델을 얹는다. 바꿀 것은 화면들이 말하는 숫자와 순서, 그리고 화면 사이를 잇는 한 번의 탭이다. 알바는 화면이 14개뿐이고 사장 화면도 "라우트를 늘리지 않는다(세그먼트·시트로)"가 규칙이다.

## 1. 지금 UI 지도 — 교육이 사는 자리

| 역할 | 탭 / 화면 | 지금 하는 일 | 교육 모델에서 맡는 자리 | 빈 자리 |
| --- | --- | --- | --- | --- |
| 직원 | 홈 (`junior/home`) | 출근 CTA, 오늘 업무 3건, 안 푼 퀴즈 경고행 | 하루의 입구. "오늘 배울 한 개"가 있어야 할 자리 | 1단계(첫 3일)가 보이지 않는다. 경고행은 건수만 말한다 |
| 직원 | 업무 채팅 → 코스 카드 (`TrainingCard`) | "다음 한 개" + 진행 알약 + 갈래별 목록(요청·새로 배정·다시 확인·통과) | 학습 루프의 "확인됨"으로 가는 문 | 통과 뒤 "혼자 해 보기"로 이어지지 않는다 |
| 직원 | 업무 채팅 → 할일 → '혼자 할 수 있어요' (`TodoScreen`) | 노하우 붙은 할일에서 자청 → 이해 확인 | "확인됨 → 혼자 함" 화살. 서비스의 핵심 접점 | 통과 후 할일에 "이제 혼자 맡아요" 표시가 없다 |
| 직원 | 이해 확인 시트 (`UnderstandingCheckSheet`) | 시작 고지(문항 수·소요) → 형태별 문항 → 결과 → 틀리면 "물어보기" | 형성평가 그 자체 | 왜 지금 이것인지(단계·중요도)를 한 줄도 말하지 않는다 |
| 직원 | 물어보기 탭 (둘러보기·AI) (`junior/chat`) | 노하우 카드 열람, AI 질문·만족도 | "봤음" 상태와 수행 지원 | 읽은 노하우·답변받은 노하우에서 확인으로 가는 길이 없다 |
| 직원 | 매장 기준 값 연습 (`junior/practice`) | 값 플래시카드, 기록 0 | 수치 지식의 자발 연습 | 재확인 전에 권하는 자리가 없다 |
| 직원 | 허브 성장 탭 (`JuniorGrowthView`) | 내가 남긴 것, 퀴즈로 확인한 노하우 | 누적 기록 | "혼자 할 수 있는 일"이 아니라 퀴즈 이력으로 읽힌다 |
| 사장 | 홈 (`owner/dashboard`) | 경고행: 자꾸 틀리는 노하우, 첫 업무 아직인 직원 | 행동 신호 두 개 | "통과했는데 계속 묻는 노하우", "한 사람만 아는 노하우"가 없다 |
| 사장 | 퀴즈 탭 (`owner/training`) | 히어로 링 "직원이 아는 노하우 %", 먼저 물어볼 것, 퀴즈 목록, 고칠 퀴즈 시트 | 교육 현황의 1층 | 대표 숫자가 도달층(알고 있나)에 머물러 있다 |
| 사장 | 퀴즈 만들기 5단계 (`owner/quiz-new`) | 받는 쪽 → 노하우 고르기 → 문항 검토 → 이름 → 사람·일정 | 교육 설계 행위 | 프리셋 이름이 단계 모델과 다른 말을 쓴다 |
| 사장 | 퀴즈 상세 (결과·문항·설정) + 사람 상세 (`owner/quiz/[id]`, `person`) | 통과/대기, 문항별 오답률 = 노하우 결함 신호, 사람별 문항 정오 | 습득층 | 사람 상세가 "어떻게 틀렸나"까지만 말하고 "혼자 맡겨도 되나"는 안 말한다 |
| 사장 | 노하우 탭 + 코치 채팅 (`owner/coach`) | 노하우 작성·수정·질문 답변 | 0단계 설계 | 노하우 한 건에 "아는 직원 n명"이 없다 |
| 사장 | 직원·급여 (`owner/staff`) | 명부·시급·매니저 지정. 퀴즈 진도는 일부러 뺐다 | (없음) | 유지. 여기에 교육을 다시 넣지 않는다 |
| 사장 | 시작하기 체크리스트 (허브) | 매장 개설 직후 할 일 | 0단계 | "첫 출근 퀴즈 만들기" 항목 확인 필요 |

## 2. 직원 동선 — 교육이 끼어드는 지점

직원은 출근하고(홈), 업무 채팅을 보고, 할일을 하고, 막히면 묻는다(물어보기). 교육은 그 네 지점에 한 칸씩 끼어들고, 어디서 들어가든 같은 **이해 확인 시트 하나**로 끝난다.

| 탭 | 교육 접점 | 지금 |
| --- | --- | --- |
| 홈 · 출근 | 첫 출근 카드 (합류 3일 · 오늘 이것만), 그 뒤 안 푼 퀴즈 | 경고행만 있음 |
| 업무 채팅 | 코스 카드: 다음 한 개 + 진행, 다시 확인 · 바뀐 것 | 있음 |
| 할일 | 혼자 할 수 있어요: 노하우 붙은 할일에서, 통과 뒤 '혼자 맡아요' | 자청만 있음 |
| 물어보기 | 읽고 묻고 → 확인: 본문 끝 '확인하기', AI 답변 아래 '확인하기' | **없음 (제안)** |

## 3. 직원 경험 — 단계마다 화면이 달라져야 한다

직원에게 단계를 설명하지 않는다. 같은 화면이 단계에 따라 다른 "다음 한 개"를 보여준다.

### 1단계 생존 — 첫 출근 3일

| 화면 | 지금 | 제안 |
| --- | --- | --- |
| 홈 | 출근 CTA 아래 "안 푼 퀴즈 n개" 경고행 | 합류 후 3일간은 경고행 대신 **첫 출근 카드** 한 장: "오늘 이것만은 — 튀김기 옆 물 금지" + 남은 개수. 누르면 노하우 본문 → 확인 순서로 연다 |
| 코스 카드 | '첫 출근' 코스가 다음 한 개를 보여줌 | 유지. 금지(t3) 노하우는 갈래 순서에서 항상 맨 위 |
| 이해 확인 시트 | 시작 고지 "3문제 · 1분" | 한 줄 더: "사고 안 나려면 이것부터예요" (안전·금지 축에 걸린 노하우만). 이유를 알면 규범 지식은 훨씬 오래 간다 |
| 둘러보기 | 카테고리별 노하우 카드 | 첫 3일은 "먼저 읽을 것" 묶음을 맨 위에. 읽으면 카드에 "읽음" 점 하나 |

### 2단계 독립 — 1~2주

| 화면 | 지금 | 제안 |
| --- | --- | --- |
| 할일 | 노하우 붙은 미통과 할일에 '혼자 할 수 있어요' 버튼 | 유지. 통과 뒤에는 그 할일에 **"혼자 맡아요" 상태어** 한 개. 할일 완료가 곧 "혼자 함" 기록 |
| 노하우 상세 (열람) | 읽기 전용 | 본문 끝에 **"이거 알겠어요 → 확인하기"** 한 버튼. 읽음과 확인 사이의 탭 수를 0으로. 문항이 없는 노하우면 버튼 없음 |
| 코스 카드 | 진행 알약 "3/5 통과" | 알약 문구를 "혼자 할 수 있는 일 3개"로 |
| 이해 확인 시트 결과 | 맞힘/틀림, 틀리면 물어보기 | 맞히면 결과 화면에 "오늘 할일에 있어요 → 할일 보기" (그 노하우가 붙은 할일이 오늘 있을 때만). 확인 직후가 적용의 최적 시점 |

### 3단계 판단 — 3~8주

| 화면 | 지금 | 제안 |
| --- | --- | --- |
| 물어보기 AI 답변 | 답 + 출처 노하우 + 만족도 | 답변 아래 **"이제 알겠어요 → 확인하기"** (출처 노하우에 문항이 있을 때). 질문이 학습으로 닫히는 유일한 자리 |
| 코스 카드 | 사장이 보낸 퀴즈만 | 합류 2주 뒤부터 **상황 문항(t5)만 담은 카드**가 자동 제안. 이름은 "이럴 땐 어떻게". 사장이 켜야 나간다(빈도 상한 안에서) |
| 이해 확인 시트 | 틀리면 "물어보기" | 상황 문항에서 틀리면 **"이 상황 노하우 읽기"**를 먼저. 갈래 지식은 사례를 다시 읽는 게 답이다 |

### 4단계 유지 — 2개월 이후

| 화면 | 지금 | 제안 |
| --- | --- | --- |
| 코스 카드 | '다시 확인할 노하우' 갈래 | 유지. 변경 델타는 **"바뀐 것 하나"** 갈래로 따로. 잊은 것과 바뀐 것은 직원에게 다른 일이다 |
| 매장 기준 값 연습 | 설정에서만 진입 | 재확인 카드에 수치 노하우가 있으면 카드 아래 "먼저 연습할래요" 한 줄. 연습은 기록 0 그대로 |
| 허브 성장 탭 | "퀴즈로 확인한 노하우 n개" | 제목을 **"혼자 할 수 있는 일"**로, 매장별로. 이직해도 남는 내 기록이라는 점이 알바에게 교육의 유일한 보상이다 |

### 5·6단계 전환·이탈

| 화면 | 지금 | 제안 |
| --- | --- | --- |
| 코스 카드 | '포지션 바뀔 때' 프리셋 | 유지. 포지션 코스는 그 자리의 1·2단계 순서(금지 먼저)를 따른다 |
| 업무 채팅 → 노하우 남기기 시트 (`CaptureKnowhowSheet`) | 직원이 요령을 제안 | 퇴사 예정이 잡히면(근무표 종료일) 같은 시트를 **"남기고 갈 요령"**으로 한 번 권한다. 새 화면 없음 |

## 4. 사장 경험 — 네 질문을 화면에 싣는다

가장 큰 변화는 화면이 아니라 **퀴즈 탭의 대표 숫자가 "알고 있나"에서 "혼자 맡길 수 있나"로 바뀌는 것**이다.

| 화면 | 답하는 질문 | 지금 | 제안 |
| --- | --- | --- | --- |
| 퀴즈 탭 히어로 | 배웠나 | 링 "직원이 아는 노하우 62%" | 링 하나는 두되 값을 **"혼자 맡길 수 있는 업무 n/m"**으로. 아래 한 줄에 "퀴즈로 확인한 노하우 62%"를 보조로 |
| 퀴즈 탭 "먼저 물어볼 것" | 무엇부터 | 필수성 점수 상위 노하우 | 유지. 줄마다 이유 라벨(안전·손실·응대)이 이미 있다 — 같은 라벨을 만들기 2단계에도 |
| 퀴즈 만들기 1단계 | 언제 | 프리셋: 첫 출근 · 정기 점검 · 단기·주말 · 포지션 | 이름을 단계 모델 말로: **첫 출근 · 혼자 맡기기 전 · 이럴 땐 어떻게 · 잊지 않게 · 자리 바뀔 때** |
| 퀴즈 만들기 2단계 | 무엇을 | 노하우 목록 + 검색 | 프리셋이 고른 단계에 맞는 지식 유형을 위로(첫 출근 = 금지·갈래, 혼자 맡기기 전 = 순서·수치) |
| 홈 경고행 | 배웠나 | 자꾸 틀리는 노하우 · 첫 업무 아직인 직원 | 두 줄 추가, 0건이면 안 그린다: **"통과했는데 계속 묻는 노하우 n개"**, **"한 사람만 아는 노하우 n개"**. 둘 다 노하우를 가리키지 사람을 가리키지 않는다 |
| 퀴즈 상세 → 사람 상세 | 배웠나 | 정답률 · 응시 횟수 · 문항별 정오 | 맨 위에 세 갈래: **혼자 맡겨도 되는 일 / 확인 중 / 다시 볼 것**. 정답률은 그 아래. 사장이 여기서 하는 결정은 "위임할까"이지 "몇 점인가"가 아니다 |
| 퀴즈 상세 문항 세그먼트 | 무엇을 (고칠 것) | 문항별 오답률 = 노하우 결함 신호 | 유지. 여기에 **"통과 후 질문 n회"**를 같은 톤으로 한 줄 더 |
| 노하우 상세 (사장) | 배웠나 | 본문 · 수정 · 보관 | 제목 아래 한 줄: **"아는 직원 3명 · 문항 2개"** 또는 **"아직 아무도 확인 전"**. 누르면 이 노하우로 퀴즈 만들기 |
| 코치 채팅 저장 확인 시트 | 무엇을 | 카테고리 · 파트 | 필수성 축에 걸리면 한 줄: "안전에 관한 노하우예요. 첫 출근 퀴즈에 넣을까요?" 토글 하나 |
| 시작하기 체크리스트 | 언제 | 매장 개설 항목들 | "첫 출근 퀴즈 한 개" 항목이 없으면 추가 |
| 직원·급여 | — | 퀴즈 진도 제거됨 | 그대로 둔다. 명부에 교육 상태를 붙이면 줄세우기로 읽힌다 |

## 5. 노하우 한 개의 여정을 화면으로

예시 노하우 "튀김기 옆에 물 두지 않기".

| 상태 | 직원 화면 | 사장 화면 | 알림 |
| --- | --- | --- | --- |
| 모름 | 코스 카드 "다음 한 개"에 제목 | 노하우 상세 "아직 아무도 확인 전" · 퀴즈 탭 "먼저 물어볼 것" | 없음. 발송은 근무일 도착 규칙 |
| 봤음 | 둘러보기 카드에 읽음 점 · 본문 끝 "확인하기" | (개인 열람은 보여주지 않는다) | 없음 |
| 확인됨 | 코스 카드 통과 갈래 · 할일에 "혼자 맡아요" | 퀴즈 상세 통과 · 노하우 상세 "아는 직원 n명" | 사장에게 응시 완료(있음). 통과·탈락은 알리지 않는다 |
| 혼자 함 | 허브 성장 "혼자 할 수 있는 일" | 히어로 링 분자 · 사람 상세 "혼자 맡겨도 되는 일" | 없음. 할일 배정 시 후보에 표시만 |
| 유지됨 | 아무것도 안 보임. 재확인 날에만 카드 | 퀴즈 탭 "다시 확인할 때가 된 사람"(있음) | 재확인 도착 푸시(있음) |
| 되돌음 — 다시 물음 | AI 답변 아래 "다시 확인하기" | 홈 경고행 "통과했는데 계속 묻는 노하우" | 없음 |
| 되돌음 — 틀림 | 결과 화면 "이 상황 노하우 읽기" · 3일 뒤 다시 | 문항 오답률에만 반영 | 없음. 실패는 사장에게 안 간다 |
| 되돌음 — 바뀜 | 코스 카드 "바뀐 것 하나" 갈래 | 노하우 저장 시 "다시 확인이 n명에게 나가요"(있음) | 변경 재확인 푸시(있음) |

새로 만드는 화면은 없다. 버튼 셋(본문 끝 확인하기, AI 답변 확인하기, 결과에서 할일 보기), 상태어 둘(혼자 맡아요, 읽음), 경고행 두 줄, 노하우 상세 한 줄이다.

## 6. 작업 우선순위 — 16건

노력은 화면 작업 기준 소(반나절)·중(며칠)·대(주 단위).

| 순서 | 제안 | 단계 | 노력 | 새 데이터·집계 |
| --- | --- | --- | --- | --- |
