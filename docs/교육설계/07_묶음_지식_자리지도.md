# 07. 묶음 지식 — 자리 지도

분기 C. 실행 순서 6번. 설거지 기물 20종의 자리 같은 지식은 노하우 한 건·문항 3개의 단위를 벗어난다. 새 화면이 아니라 **새 노하우 유형 하나와 새 문항 형식 하나**가 필요하다.

## 1. 문제

설거지 하나에 기물 10~20종과 그 자리가 딸려 있고, 그걸 한 번에 익혀야 일이 된다. 카드 한 장과 문항 3개로는 절대 안 된다. 지금 노하우 구조(situation·steps·do·dont·standard·photos)에는 "이름 20개와 자리 20개"를 담는 모양이 없다. 사장은 긴 본문 하나로 쓰거나 노하우 20개로 쪼개야 하고, 둘 다 배우는 쪽에서는 최악이다.

설거지만이 아니다. 재고 선반, 메뉴별 컵·리드, 기기 버튼, 청소 도구 자리, 테이블 번호가 전부 같은 모양이다. 매장 지식의 절반은 "무엇이 어디에"이고, 지금 서비스는 그 절반을 글로만 받는다.

## 2. 교육학이 말하는 것

- **외우게 하지 말고 찾게 하라.** 20개 자리는 머릿속 지식이 아니라 세상 속 지식이다. 선반 라벨, 사진 지도가 암기보다 먼저다. 앱의 역할은 "가르치기"가 아니라 "현장에서 보며 하게 하기"다.
- **공간으로 묶어라.** 사람은 목록 20개보다 사진 한 장 위의 위치 20개를 훨씬 잘 기억한다. 설거지대 사진에 핀 20개가 글 20줄보다 낫다.
- **하루에 다 주지 말고 나눠라.** 20개를 첫날 주면 3개 남는다. 작업기억은 한 번에 4개 안팎이다. 자주 쓰는 5개부터, 나머지는 며칠에 걸쳐.
- **확인은 "찾아봐"로.** 묶음 지식의 올바른 확인은 사진에서 자리를 탭하는 것이지 보기 네 개 중 고르는 것이 아니다. 성공 기준은 "안 묻고 다 찾는가"다.
- **사장의 5분 동행을 대체하려 하지 마라.** 기물 자리는 사장이 한 바퀴 돌며 보여 주는 게 가장 빠르다. 앱은 그 5분 뒤에 "기억 안 나면 여기"를 맡는다.

## 3. 자리 지도 노하우 — 화면별 제안

| 자리 | 지금 | 제안 |
| --- | --- | --- |
| 노하우 작성 (사장 코치 채팅) | 글로 적거나 사진 첨부 | **자리 지도 노하우**: 사장이 설거지대 사진 한 장 찍고, 사진 위를 탭해 핀을 찍고, 이름을 말로 부른다(음성 입력 재사용). 20개면 2분. 사장이 이미 하는 "한 바퀴 돌며 보여 주기"와 같은 동작 |
| 노하우 열람 (직원 둘러보기) | 본문 읽기 | 사진 위 핀을 탭하면 이름. 검색에서 "집게 어디"를 치면 사진이 그 핀으로 열린다. 현장에서 보며 하는 수행 지원이 먼저다 |
| 코스 카드 | 노하우 1건 = 항목 1개 | 자리 지도는 **오늘 몫 5개**로 쪼개져 여러 날에 걸쳐 나간다. 자주 쓰는 것부터(사장이 핀 순서로 정한다). 카드 문구는 "설거지 자리 5/20" |
| 이해 확인 시트 | 4지선다·짝 찾기 등 17종 | 새 형식 **"사진에서 찾기"**: 이름을 부르면 사진에서 그 자리를 탭. 틀리면 정답 핀이 켜지고 다음으로(실패 미저장 원칙 그대로). 지뢰 밟기 렌더러의 사진 판 |
| 할일 '혼자 할 수 있어요' | 노하우 문항 3개 | 설거지 할일은 복합 지식이다. 자청 확인은 "자리 5개 찾기 + 금지 1문항 + 순서 1문항"처럼 부분별로 섞인다. 업무에 붙은 노하우가 여러 건이면 이미 이렇게 동작한다 |
| 사장 퀴즈 탭 | 노하우 단위 통과 | 자리 지도는 "직원별 20개 중 찾는 것 n개"가 아니라 **"설거지 자리 — 혼자 찾는 직원 3명"**으로만. 핀 단위 점수는 줄세우기다 |

## 4. 데이터와 규칙

| 항목 | 형식 | 규칙 |
| --- | --- | --- |
| 자리 지도 노하우 | 사진 1장 + 핀 N개(좌표·이름). 음성으로 이름 입력 | 핀 5개 이상이면 묶음. 코스 카드가 5개씩 쪼개 발송 |
| 사진에서 찾기 문항 | 핀 중 하나의 이름을 묻고 사진에서 탭. 허용 반경은 핀 간 거리의 절반 | 같은 사진의 다른 핀이 오답 후보. 채점은 서버 |
| 재확인 간격 | 유형별 기본값 (02 축 1) | 수치는 짧게, 이름·자리는 길게. `schedule.ts` 상수 하나로 가능 |
| 유형 판정 | `detect.ts`에 자리(t7 또는 별도 kind) 추가 | 핀이 있으면 자리. 자리는 공간 암기(02의 5방식 중 암기) |

## 5. 관계

- 02의 축 4(지식의 양)와 10유형의 1번 자리가 이 문서의 근거다.
- 04(초기 가치)에서 쓸 사장이 생긴 뒤에 가치가 있다. 그래서 실행 순서 6번.
- 10(서비스 반영 형식)에 데이터 유형 행으로 들어간다.
