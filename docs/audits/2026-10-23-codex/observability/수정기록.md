# OBS-01 수정 기록

사용자 승인: 2026-10-23 후속 메시지에서 4번 수정 요청.

제품 변경은 src/lib/analytics/track.ts의 routeOf 한 곳이다. 공유 퀴즈 경로의 토큰을 /q/[token]으로 바꾼다. 오류 client_errors와 이용 app_events가 같은 함수를 사용하므로 둘 다 적용된다. 일반 화면 경로와 네이티브 null 동작은 유지한다. 서버 및 DB 계약 변경은 없다.

검사: test-route-token.cjs는 실제 모듈을 실행하고 전송만 대역으로 대체한다. 수정 전 공유 토큰/인코딩 토큰/마지막 슬래시 3사례 실패, 정상 경로 등 4사례 통과. 수정 후 7사례 모두 통과했다. 각 사례에서 두 기록의 route를 함께 확인한다. 전송 거절이 앱으로 예외를 던지지 않는 기존 동작도 확인했다.

증거: before-track.ts.txt, red.log, green.log. 로그 끝에 해시와 실행 시각을 남겼다. 실제 토큰/계정/운영 데이터는 쓰지 않았다.

범위: 이 변경은 확인된 route 필드의 토큰 복제를 막는다. 외부 분석 SDK의 자동 URL 수집이나 임의 error.message/meta에 대한 전체 개인정보 검사를 완료했다는 뜻이 아니다. 과거 로그를 지우거나 기존 링크를 변경하지 않는다. 배포하지 않았다.
