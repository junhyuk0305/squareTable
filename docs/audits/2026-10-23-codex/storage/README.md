# 저장 동시성 증거 실행

저장소 루트에서 `node docs/audits/2026-10-23-codex/storage/base.cjs`로 실행한다. 수정 전 재현은 환경변수 AUDIT_BEFORE=1을 설정하고 같은 명령을 실행한다. before.ts.txt는 RED용 원본이다. 제품 파일을 바꾸지 않는다.

red/green 파일과 수정결과.md는 당시 증거다. current-results.log는 저장소로 이관한 스크립트의 새 실행이며 14개 시나리오가 통과했다. 소스 변경 감지 0개다. 저장소 이관에서 경로만 상대화하고 전체 소스 snapshot 저장 및 기존 결과 덮어쓰기를 제거했다. 결과는 stdout으로만 출력된다.

제품 수정은 이미 다른 세션의 커밋 448afcb502da9b38f84926b151d06fd804ed579a에 포함됐다. 이번 폴더 추가는 제품 재수정이 아닌 감사 증거 보존이다. 과거 결과의 로컬 사용자 경로만 <repo>/<original-evidence>로 치환했다. 원본 파일은 외부 산출물에 그대로 있다. 전체 snapshot과 db.ts는 복사하지 않았다. 실제 모듈 실행이며 DB 전송과 응답 순서는 모의했다. 실제 UI·기기·운영 검증이 아니다.
