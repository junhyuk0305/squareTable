Question 2

2긴 인수인계서(텍스트·PDF·사진)를 한 번에 노하우로?

긴 텍스트를 붙여넣거나, PDF·사진(PNG/JPG)을 올려 한 번에 여러 노하우로 만드는 경로는 현재 전부 없습니다. 사진은 "첨부"만 되고 내용은 읽히지 않습니다.

입력 방식현황왜 안 되는가 (코드 근거)
긴 텍스트
N자 붙여넣기		 불가 입력창 maxLength={1000} — 1,000자 초과는 입력 자체가 잘림. Edge도 MAX_RAWTEXT_LEN=8000으로 컷. 게다가 위 6개 상한. 실제 인수인계서(보통 수천 자·10+개 항목)를 한 번에 담을 수 없음.
PDF 불가 파일 선택기가 accept='image/*'로 PDF 선택 불가. PDF 텍스트 추출·파싱 코드가 프로젝트 어디에도 없음.
PNG / JPG
(문서 사진)		 첨부만 사진은 photos[]로 카드에 첨부됨. 하지만 Edge callGemini는 parts:[{text}]만 전송(멀티모달 아님) → 이미지 속 글자를 노하우로 추출하지 않음. 사진 붙은 빈 노하우가 됨. + 웹 전용.

함께 결정할 것 · 리스크

  • 비용. 비용청크 수 × Gemini 콜. 30항목 문서면 최대 ~5콜(청크당 6). flash-lite 유지 시 문서당 수 원 수준이나, 이미지 OCR은 토큰이 큼 → 페이지 수 상한·해상도 다운스케일 필요.
  • 레이트리밋. 순차 배치가 사용자당 RATE_PER_MIN_USER=10에 걸릴 수 있음 → 대량 모드는 카운팅 완화 or 청크 묶음 전송 검토.
  • 스캔 품질. 손글씨·흐린 사진 OCR은 오류율이 높음 → 검토 체크리스트가 필수 안전장치(자동 저장 금지, 사장 확인 후에만).
  • 개인정보. 인수인계서에 직원 연락처·급여가 섞일 수 있음 → OCR/저장 전 민감정보 안내 + 원본 첨부는 매장 격리(RLS) 확인.
  • 범위 결정. 1차는 텍스트 붙여넣기(제한 해제) + 청킹만으로도 인수인계서의 80%를 커버 → PDF/이미지 OCR은 2차로 나눠도 됨.
TL;DR

≡한 장 요약

  • 다중 노하우 분리 등록 — 코드상 됨(최대 6개). 배치 저장·카운트 정합까지 커밋 완료. 단 배포 웹번들은 7/4·Edge 재배포 미확인 → 재빌드+재배포 후 실LLM 재현으로 확정.
  • 긴 텍스트 — 입력창 1,000자 제한으로 불가.
  • PDF — 선택 자체가 안 됨, 파싱 없음 → 불가.
  • 사진(PNG/JPG) — 첨부만 되고 내용은 안 읽힘(멀티모달 아님) → 노하우로 등록 불가.
  • 해결안 — "문서로 한 번에" 모드 신설: 소스→텍스트화→청킹→청크별 square 반복→체크리스트 검토→배치 저장. 기존 파이프 대부분 재사용, 신규는 진입화면·OCR task·청킹 유틸.
  • 추천 1차 범위 — 텍스트 붙여넣기 제한 해제 + 청킹(6개 상한 → 문서 30개)만 먼저. PDF·이미지 OCR은 2차.
